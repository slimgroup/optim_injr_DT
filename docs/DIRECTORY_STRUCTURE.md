## File Category Descriptions

### Core Modules (src/)
- Contains the main Julia module code for the project
- These files are referenced by other scripts

### Script Files (scripts/)
- **shell/**: All Shell scripts, including SLURM job submission scripts
- **julia_scripts/**: All Julia scripts, including data processing, plotting, analysis, etc.

### Data Files (data/)
- Experiment data, intermediate results, configuration files, etc.
- `scripts_data/`: Data files generated by scripts

### Image Files (plots/)
- All generated image files
- Organized by experiment type

## File Naming Conventions

- Script files use lowercase letters and underscores: `plot_pof_cvar.py`
- Module files use lowercase letters and underscores: `optim_inject.jl`
- Data files use descriptive names: `injr_dist_1_to_32.jld2`

## Path References

Path references in scripts have been updated:
- `src/optim_inject.jl` → Remains in src directory (core module)
- `src/*.sh` → Moved to `scripts/shell/`
- `src/cases.list` → Moved to `scripts/shell/`
- Old version scripts → Moved to `scripts/*/archive/`

## Maintenance Guidelines

1. **New scripts**: Add to appropriate subdirectory in `scripts/`
2. **New data**: Add to appropriate subdirectory in `data/`
3. **New images**: Add to appropriate subdirectory in `plots/`
4. **Old files**: Move to `archive/` directory instead of deleting directly
5. **Core modules**: Only modify files in `src/`, keep interfaces stable
