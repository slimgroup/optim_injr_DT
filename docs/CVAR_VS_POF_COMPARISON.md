## CVaR 为什么比 POF 更保守？

### 1. **POF (Probability of Failure)**
- **定义**: POF = P(r < 0) = 违反压力边界的概率
- **特点**: 只关心"是否违反"，不关心"违反多少"
- **例子**: 
  - 情况 A: 100 个点中有 1 个点轻微违反（r = -0.01 MPa）
  - 情况 B: 100 个点中有 1 个点严重违反（r = -10 MPa）
  - **POF 相同** = 0.01，但情况 B 明显更危险！

### 2. **CVaR (Conditional Value at Risk)**
- **定义**: CVaR = E[L | L ≥ Q_α]，其中 L = max(0, -r) 是损失
- **特点**: 不仅关心"是否违反"，还关心"违反的严重程度"
- **例子**:
  - 情况 A: CVaR ≈ 0.01（轻微违反）
  - 情况 B: CVaR ≈ 10.0（严重违反）
  - **CVaR 能区分这两种情况！**

### 3. **为什么 CVaR 更保守？**

```
POF 视角：
- "只要违反概率 ≤ 1%，我就接受"
- 可能接受：偶尔严重违反但概率低的情况

CVaR 视角：
- "不仅要违反概率 ≤ 1%，还要平均违反程度 ≤ γ"
- 拒绝：即使概率低，但一旦违反就很严重的情况
```

**直觉类比**：
- **POF**: "这个投资有 1% 概率亏损" → 可能接受（不知道亏多少）
- **CVaR**: "这个投资有 1% 概率亏损，但平均亏损是 100 万" → 更谨慎

## CVaR 的数学直觉

### CVaR 的定义

```
CVaR_α = E[L | L ≥ VaR_α]

其中：
- L = max(0, -r) 是损失（压力违反的程度）
- VaR_α = Q_α(L) 是 α-分位数（例如 α=0.05 表示 95% 分位数）
- CVaR_α 是"超过 VaR_α 的所有损失的平均值"
```

### 为什么更保守？

1. **考虑尾部风险**：
   - POF 只看"有多少点违反"
   - CVaR 看"违反的点平均违反多少"

2. **惩罚极端情况**：
   - 即使违反概率相同，CVaR 会惩罚更严重的违反
   - 这导致优化器选择更安全的注入率

3. **实际意义**：
   - POF = 0.01: "1% 的概率会违反"
   - CVaR = 0.5: "如果违反，平均违反程度是 0.5 MPa"
   - CVaR 提供了**违反的严重程度**信息
