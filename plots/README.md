# Plots and figures

Start with **[latest/](latest/README.md)** for the 21 current selected figures.
Its [HTML gallery](latest/index.html) opens locally in a browser. Relative links
keep a single copy of each original PNG and retain the exact export filenames.

| Directory | Role |
|---|---|
| `latest/` | Current selections only; concise personal browsing view |
| `paper_figures/` | Original selected exports, supporting caches, and historical scientific inputs |
| `DT_control/` | Step-1 statistical exports and simulation/video output |
| `step{2,3,4}_paired_posterior_stats/` | Monitoring-step statistical analysis |
| `posterior_field_uncertainty*/` | Original posterior field exports and source arrays |
| `posterior_sample_videos/` | Posterior presentation videos |
| `diagnostics/`, `step2_prior_comparison_32samples/` | Diagnostic and comparison workflows |

Nineteen superseded layout previews have moved to
`archive/figure_previews/`; the old-to-new map and checksums are recorded in
[the cleanup receipt](../docs/reference/cleanup_receipt.json). Sixty-four old
exports are no longer tracked, with local originals retained. Selected figures
and numerical inputs were not replaced or rerun.

Some historical-looking folders are still inputs. The v6 statistical style
references, original posterior caches, prior monitoring steps, and 64-member
forward runs remain available because later figures depend on them. Different
experiments or sensitivity factors are not interchangeable versions.

See [the figure manifest](../docs/reference/PAPER_FIGURE_MANIFEST.md) and
[asset registry](../docs/reference/paper_assets.json) before changing selections.
